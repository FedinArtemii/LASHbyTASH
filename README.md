# LASH by TASH

Лендинг студии. Тексты, изображения и кнопки главной страницы редактируются в редакторе блоков WordPress. В GitHub Pages публикуется её статический экспорт из каталога `docs/`.

- Публичный адрес [GitHub Pages](https://fedinartemii.github.io/LASHbyTASH/).
- Запись [в группе ВКонтакте](https://vk.ru/lashbytash).
- Репозиторий [FedinArtemii/LASHbyTASH](https://github.com/FedinArtemii/LASHbyTASH).

## Локальный запуск

Понадобятся PowerShell и PHP для Windows с расширениями из стандартного каталога `ext` дистрибутива PHP. Команда устанавливает изолированный WordPress с SQLite в игнорируемый каталог `.local`, если установки ещё нет, и запускает сервер на `127.0.0.1:8087`.

```powershell
./scripts/local.ps1 -Start
```

Откройте [главную](http://127.0.0.1:8087/) или [редактор WordPress](http://127.0.0.1:8087/wp-admin/). Данные входа записаны в `.local/admin.txt`. В панели управления выберите «Страницы → Главная». Повторный запуск сохраняет правки, сделанные в редакторе.

## Обновление GitHub Pages

1. Сохраните изменения страницы в WordPress.
2. Запустите `./scripts/export.ps1` из PowerShell.
3. Отправьте изменения в `main`. Источник публикации GitHub Pages — `main`, каталог `/docs`.

Экспорт переносит изображения из темы и изображения, загруженные через медиатеку, и заменяет их локальные адреса на относительные.
